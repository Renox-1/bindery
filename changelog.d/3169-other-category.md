### Fixed
- **A category you set on an indexer is no longer replaced with 7020 or 3030** (#3169). An indexer whose categories held nothing in the Books (`7xxx`) or Audio (`3xxx`) range, such as a tracker set to `8000` because it files its books under Other, was searched with the standard ebook or audiobook ID instead of the one you typed, and the search debug showed `categories: 7020`. Bindery now searches the `8xxx` IDs an indexer lists as typed when it lists nothing in the requested media's range. An indexer with no `8xxx` ID keeps the old fallback. Reported by gianfelicevincenzo.
