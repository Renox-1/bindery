### Fixed
- **The Advanced settings tab no longer lists Bindery's own startup markers as unrecognised keys.** The five `backfill.*_rev` rows (dedup key, sort keys, book sort key, search key and ASIN case) record which normalizer revision each startup backfill last ran at. They were missing from the settings registry, so the tab labelled them "Unrecognised", said nothing read them, and offered a Remove button. They now show as internal bookkeeping. Removing one is harmless but makes the next start repeat that backfill once, and a new test fails when a backfill marker has no description.
