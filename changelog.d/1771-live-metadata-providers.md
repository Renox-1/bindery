### Changed
- **Changing the primary metadata provider or the Google Books key now takes effect immediately, no restart** (#1771). Picking BnF, DNB, NB, Hardcover or OpenLibrary under Metadata Profiles, or saving a Google Books key under API Keys, used to be stored and then ignored until Bindery restarted, so a book added in between still came in through the old provider. The next lookup now uses the new setting. Lookups already running when you save finish on the provider they started with. Authors already in your library stay linked to the provider they were added from, as before.
